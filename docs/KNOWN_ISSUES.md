# 已知问题与后续改进

- 预览版本；尚不应宣布正式 V1.0 验收完成。
- 底图 1672×941，Retina 大窗口清晰度低于原生 2560×1440 生产素材。
- 云原图在黑底下仍有少量彩边；须在实际显示尺寸目视核验和精修。
- 预览三版已加入局部海面纹理流动和三簇原画前景花草摆动；中远景草甸仍静止。
  前景使用柔边遮罩与分段剪切近似植物弯曲，没有逐株分离；大幅运动下柔边处仍可能出现轻微重影。
  海中礁石用保守遮罩保护，部分近礁水域保持静止。完整植物骨骼与高精度岸线需要分层生产素材。
- 日光是分区色温、亮度与空间渐变，不是重绘的全场景昼夜照明。飞鸟暂未启用。
- 预览二版已改为原生“设置 → 通用设置 → 海风与草甸”，移除了浮动叶片。
  依赖官方 0.2.0-rc.2 的 settings.general.item 插槽，其他版本须重新核验。
- 未知背景主题可能不参与冲突锁；需人工保证只启用一套背景。
- 壳体透明 CSS 针对官方 0.2.x macOS DOM；后续升级须回归。
- 真实隔离 Desktop 的设置/插件管理及主界面已验证；完整登录工作流、真实代码/Diff、
  Intel Mac、OS 最小化、功耗和长期运行仍未验证。深浅色与减少动态效果通过原生
  Renderer 中的 media 模拟验证，未更改 macOS 全局偏好。
- 不使用私有电池 API，Eco 需手动选择。localStorage 禁用时会显示提示，不能跨重启保存。
